# **Дискорд Яйца** 

Моя переделка [NewerOldCord](https://github.com/FrCynda/NewerOldCord) от _FrCynda_ (ответвление [oldcord](https://github.com/milbits/oldcord) от _milbits_)

---

Леплю её конкретно под свой вариант браузера (на данный момент это сборка последнего хромиума), обновляю по мере обнаружения недостатков и выхода новых обновлений дискорда. Кроме поддержки вида оригинальной темы (автор оригинала этим не особо занимается, насколько я понял) добавил несколько изменений, которые мне самому показались славными. Если кому нужно будет их вырезать, пишите мне в ДС: _caxap04ek_

В приложении и других браузерах она скорее всего будет поломана, адаптировать не планирую (пока сам не поменяю браузер). Переводить подсказки на язык международного общения, он же — инглиш лангуаге, тоже не вижу смысла. 

В принципе не планирую распространять эту тему. Страницу создал чисто чтобы часть кода (изменённый второй импорт из оригинала) закинуть через импорт, чтоб компактней всё было. Остальное — просто на всякий случай, потому что мне сейчас совершенно нечего делать.

## УСТАНОВКА: 
Скопировать содержание файла [balls.css](https://github.com/ArturBalls/DiscordBALLS/blob/main/balls.css) в quickCSS Vencord (или другого мода для дискорда)

Или вставить тудой эту строчку:

```css
@import url("https://raw.githubusercontent.com/ArturBalls/DiscordBALLS/refs/heads/main/balls.css");
```
